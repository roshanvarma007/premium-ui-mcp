# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, critique work rather
than people, and keep discussions focused on making the project better.
Harassment, personal attacks and discriminatory language are not tolerated in
issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer through the contact
details on the maintainer's GitHub profile
([@roshanvarma007](https://github.com/roshanvarma007)). Reports are handled
confidentially. Maintainers may remove, edit or reject contributions, and may
temporarily or permanently ban contributors, for behavior they deem harmful, as
described in the Contributor Covenant's enforcement guidelines.
