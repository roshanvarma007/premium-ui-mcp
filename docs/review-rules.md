# `review_ui` rules

Every rule is a pure function over the supplied files. Comments are ignored, and generated
token files (anything with the `Generated by premium-ui-mcp` header, or named like
`tokens.css`, `ui/theme/Color.kt`, `res/values/colors.xml`) are exempt from the
"hardcoded" rules. Findings are capped at 8 per rule per file. Each rule can cost at most a
fixed share of the 100-point score (errors 36, warnings 16, info 4), so one noisy rule cannot
zero it.

Severity: **error** = must fix (accessibility or broken), **warn** = fix before presenting,
**info** = suggestion.

Passing `direction_id` enables direction-aware checks: the exact spacing scale, accent
family, default fonts, and Tailwind default-palette classes.

## Common (all platforms)

| Rule | Severity | Detects | Fix |
|---|---|---|---|
| `contrast-fail` | error | A text/background pair resolvable from literals or tokens below WCAG AA (4.5:1, or 3:1 for large text) | Use text / text_muted tokens or the suggested passing color |
| `hardcoded-color` | warn | Color literals (hex, rgb, hsl, `Color(0x..)`, `#RRGGBB` in layouts, `bg-[#..]`) outside token files | Reference a color token |
| `too-many-accents` | warn | More than one non-semantic accent hue family (one extra beyond the direction accent when a direction is given) | Keep one accent; semantic colors for meaning only |
| `pure-black-white` | warn | `#000` text on `#FFF` background | Use tinted neutrals (text on bg/surface) |
| `font-size-sprawl` | warn | More than 7 distinct font sizes | Map text to the 7 type roles |
| `tiny-text` | warn | Text under 12px / 12sp | Caption or label role at minimum |
| `off-grid-spacing` | warn | Margin/padding/gap values off the direction scale (or off the 4-grid without a direction). Values of 2 or less are ignored | Use spacing tokens |
| `radius-sprawl` | warn | More than 3 distinct corner radii (full rounding excluded) | sm / md / lg only |
| `uniform-pill-everything` | warn | At least 4 radii, with 60% or more of them pill-shaped or 24+ | Full rounding only for chips and avatars |
| `shadow-everywhere` | warn | 5 or more shadow / elevation declarations | Borders first; elevation for overlays |
| `default-font-fallthrough` | warn | Inter/Roboto/Arial/Helvetica (or generic system fonts when a direction is set), `font-sans`, `FontFamily.Default`, `android:fontFamily="sans-serif"` | Use the direction font tokens |
| `emoji-as-icon` | warn | Emoji in UI text (©, ™, arrows and other text symbols are not flagged) | One icon set, one style |
| `low-touch-target` | warn | Interactive elements under 44px (web) or 48dp (Android) | `--size-touch`, `min-h-touch`, `Spacing.minTouchTarget`, `@dimen/ds_touch_target` |
| `gradient-usage` | warn | `linear/radial/conic-gradient`, `bg-gradient-*` / `bg-linear-*`, `Brush.*Gradient`, `<gradient>`. Off when the direction `permits.gradients` | Flat surfaces |
| `glassmorphism` | warn | `backdrop-filter: blur`, `backdrop-blur-*`, `Modifier.blur`. Off when the direction `permits.blur` | Opaque surfaces with a hairline border |
| `glow-shadow` | warn | Colored shadows with large blur or zero offset, `shadow-[..color..]`, `shadow-indigo-500/50`, `Modifier.shadow(spotColor = …)` | Neutral elevation tokens |
| `ai-palette` | warn | Framework default colors (Material baseline purple and teal, Tailwind indigo/violet/purple, slate-900 navy), Android Studio template colors (`Purple80`, `purple_500`), indigo/purple Tailwind classes, navy + cyan/purple combinations | Use a design direction palette |

## Web core (html, tailwind, react, nextjs)

| Rule | Severity | Detects | Fix |
|---|---|---|---|
| `missing-viewport` | error | HTML document without `<meta name="viewport">` (not checked for JSX frameworks, which add it) | Add the viewport meta |
| `missing-lang` | warn | `<html>` / `<Html>` without `lang` | `lang="en"` (or the right language) |
| `img-alt` | warn | `<img>` / `<Image>` without `alt` | Describe the image, or use `alt=""` if it is decorative |
| `clickable-non-interactive` | warn | `onclick` / `onClick` on div, span, li, p, section, article or img without role, tabIndex and a key handler | Use `<button>` or `<a href>` |
| `icon-button-label` | warn | `<button>` whose content is only an icon, with no `aria-label` / `title` / visually-hidden text | Add `aria-label` |
| `focus-outline-removed` | warn | `outline: none` / `outline-none` with no `:focus-visible` style anywhere | Visible focus ring |
| `theme-flash` | warn | Theme set on load or in `useEffect` with no inline pre-paint script | Inline script in `<head>` before stylesheets |
| `reduced-motion` | warn | Animations (`@keyframes`, `animation:`, `animate-*`, framer `motion`) with no reduced-motion handling anywhere | `prefers-reduced-motion`, `motion-safe:`, `useReducedMotion()` |
| `px-font-size` | info | `font-size` in fixed px in stylesheets | `var(--text-*)` or `.t-*` classes |
| `tailwind-arbitrary-value` | warn | Arbitrary values like `text-[17px]`, `p-[13px]` (layout sizing such as `w-[..]`, `grid-cols-[..]`, `aspect-[..]` is allowed) | Theme utilities |
| `tailwind-default-palette` | warn | Default palette classes (`bg-blue-500`) when a direction is set | Direction color utilities |

## Next.js

| Rule | Severity | Detects | Fix |
|---|---|---|---|
| `next-font-link` | info | Raw `<link>` to Google Fonts | `next/font/local` or `next/font/google` |
| `next-img` | info | Plain `<img>` in a component | `next/image` |
| `use-client-root` | info | `'use client'` at the top of `app/layout`, `app/page` or `app/template` | Keep roots as Server Components |

## Jetpack Compose

| Rule | Severity | Detects | Fix |
|---|---|---|---|
| `compose-literal-font-size` | warn | `fontSize = N.sp` in screen code | `AppTheme.type.*` |
| `compose-literal-radius` | info | `RoundedCornerShape(N.dp)` in screen code | `AppTheme.shapes.*` |
| `compose-literal-padding` | info | `padding(N.dp)` literals (suppressed when `off-grid-spacing` already fires) | `Spacing.sN` |
| `compose-default-theme` | warn | `MaterialTheme { }` without a color scheme | Generated `AppTheme { }` |
| `compose-dynamic-color` | warn | `dynamicLightColorScheme` / `dynamicDarkColorScheme` | Remove; use the direction palette |

## Android XML

| Rule | Severity | Detects | Fix |
|---|---|---|---|
| `xml-text-size-unit` | warn | `android:textSize` in dp or px | TextAppearance styles (sp) |
| `xml-literal-text-size` | info | `android:textSize="Nsp"` in layouts | `?attr/textAppearance*` |
| `xml-font-resource` | warn | `android:fontFamily` not from `@font/` or a theme attribute | Theme font or `@font/…` |
| `xml-text-appearance` | info | `textAppearance` not from `?attr/textAppearance*` or `TextAppearance.App.*` | Use a direction role |

## Quality gates

- `fixtures/bad-<platform>/` must produce every rule listed in its `expected.json`.
- `fixtures/good-<platform>/` must produce no findings at all.
- `fixtures/realistic/<platform>/` (5 snippets per platform) and the sample apps in
  `examples/` must produce no errors or warnings.
